# Bio-Smart

Bio-Smart adalah proyek website yang berfungsi sebagai halaman profil atau landing page modern untuk menampilkan informasi biodata, profil, atau data penting secara rapi dan menarik. Proyek ini dibuat dengan menggunakan HTML, CSS, dan JavaScript agar tampilan lebih responsif, ringan, dan mudah dikembangkan.

## Deskripsi

Proyek ini dibuat untuk membantu pengguna menampilkan informasi diri, brand, atau profil usaha dalam satu halaman yang bersih dan profesional. Dengan desain yang sederhana namun elegan, Bio-Smart cocok digunakan sebagai halaman personal, portfolio, atau tampilan profil digital yang ingin tampil lebih modern.

## Fitur

- Tampilan responsif untuk perangkat desktop dan mobile
- Desain yang bersih dan modern
- Struktur halaman yang mudah dimodifikasi
- Menggunakan teknologi dasar web yang ringan dan mudah dipahami
- Cocok untuk profil personal, brand, atau landing page sederhana

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
